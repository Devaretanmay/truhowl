# Truhowl Brand Foundations (Phase 2)

## Wordmark
**Truhowl** — capital T, lowercase rest, single word. Never `TruHowl`,
`TrueHowl`, `TRUHOWL` (screaming caps reserved for CLI banners only).

## Voice
Watchful, technical, trustworthy, independent. Evidence first, minimal AI
language. Verified repairs and loud refusals — never faked passes.

## Visual language
Signal + propagation + verification. Abstract waveform mark, subtly
reminiscent of a howl. No wolf head, no paw, no mascot.

## Palette
Dark-neutral base, one sharp signal color for status accents, clean
typography. Infrastructure/control aesthetic, not AI-chat aesthetic.
Restrained motion only.

## CLI identity
`truhowl` is the only public entrypoint. `koyote` remains a deprecated
alias during transition. Public verbs: `status`, `ask`, `check`,
`migrate`, `consult`, `login`, `doctor`. `hunt` is a deprecated alias
for `migrate`. Internal engine names (Howl/Hunt personas, finding,
provider, drift) never appear in new user-facing copy.
