## 2. Engine loop (what runs inside)

```mermaid
flowchart TD
    EVENT["ANY CHANGESOURCE<br/>dependency bump · registry · schedule · PR webhook"] --> DETECT["DETECT IMPACT<br/>AST graph · callsites · evidence"]
    DETECT --> MEM["SEMANTIC PATTERN MEMORY<br/>verified patterns in .koyote/knowledge/<br/>saves customer tokens"]
    MEM --> AI["SHARED AI REASONING ENGINE<br/>customer BYOK provider<br/>sole author of changes & reviews"]
    AI -->|Consult: Howl| ADVICE["CONSULT: IMPACT ANALYSIS<br/>what changed · affected · why · what not to change<br/>files GitHub Issue · 0 files touched"]
    AI -->|Work: Hunt| PATCH["WORK: SURGICAL REPAIR<br/>generated by customer's AI provider"]
    PATCH --> TEST["KERNEL SANDBOX VERIFICATION<br/>Landlock/Seatbelt · real tests · zero blast radius"]
    TEST -->|green| PR["EVIDENCE TRUST PR<br/>BLAKE3 receipt · verified commit"]
    TEST -->|red| RETRY["AI SELF-REPAIR LOOP<br/>feeds test failure back to model"]
    RETRY --> AI
    PR --> FLYWHEEL["UPDATE KNOWLEDGE BASE<br/>caches verified pattern for future token savings"]
```

## 4. State on disk

```text
<repo>/.koyote/
  graph.json            dependency graph (Rust AST engine)
  index_state.json      commit SHA + mtimes (incremental re-index)
  knowledge/            verified patterns (sdk/stripe/11.18.0__13.0.0.json…)
  history.json          auditable migration ledger
  snapshots/            pre-execution BLAKE3 rollback

~/.koyote/
  credentials.json            global BYOK (0600)
  installations/{id}.json     repos + READY states (0600)
  installations/{id}/{repo}   scoped BYOK credentials (0600)
  repos/{owner}__{repo}       managed git checkouts
```
